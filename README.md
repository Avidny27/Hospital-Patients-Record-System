# Hospital Patients Record System

A C-based hospital management system used to manage patient records efficiently.

## Features
- Add patient
- Search patient
- Delete patient
- Update records
- Display all patients

## Technologies Used
- C Language
- Structures
- Functions
- File Handling

## Future Improvements
- GUI version
- Database integration
- Login system
- Appointment system

## How to Run
1. Clone the repository
2. Compile using GCC
3. Run the executable

```bash
gcc main.c -o hospital
./hospital
